## 🛠️ What I Work On

| Area | Details |
| :--- | :--- |
| **Telegram bots** | Anonymous chat bots and file-sharing bots that hand out links — built on `python-telegram-bot` and plain Python |
| **Web backends** | Native PHP gateways, verification flow engines, admin panels, and small REST APIs |
| **Server & mobile tooling** | VPS bootstrap scripts, LAMP stacks on Termux, one-off automation in shell |
| **Networking** | Packet-capture and traffic-analysis tooling, including ports of older C projects to Python |

Most of what I ship starts life as a personal itch — a script I needed, a server I had to
rebuild twice, a bot I wanted to try. Some of it stays private.

### [`keygate`](https://github.com/ngewa/keygate)

**Ref Key Manager — gateway, video-to-key & multi-link manager**

A verification flow engine with daily key generation and an AJAX admin panel, written in
**native PHP 8.3 with no framework**. Paired with SQLite in WAL mode, vanilla JS with
Fetch API, and a small Python client.

Deliberately dependency-free — no Composer, no npm, no build step. You clone it and it runs.

`PHP 8.3` `SQLite · WAL` `Vanilla JS` `Python client`

and tested without carrying a laptop around.

`Shell` `Termux` `Apache` `MySQL` `PHP`
